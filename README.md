# Для Ани ❤

Маленький романтический квест на WebGL (three.js): два вопроса (имя «Анюта» и самый счастливый день) и письмо в конце.

Сайт статический — открывается через GitHub Pages, сборка не нужна.

- `index.html` — разметка экранов
- `style.css` — оформление
- `scene.js` — WebGL‑сцена (небо, сердечки, лепестки, 3D‑сердце)
- `main.js` — логика вопросов
- `audio.js` — тихая «музыкальная шкатулка» на WebAudio
